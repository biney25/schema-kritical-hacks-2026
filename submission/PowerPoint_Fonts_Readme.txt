POWERPOINT AND PDF VERSIONS

For uploading or presenting on another computer, use Schema_Kritical_Submit.pptx or Schema_Kritical_Round1.pdf. Their slide appearance is fixed and does not depend on installed fonts.

For editing text, diagrams and tables, use Schema_Kritical_Round1.pptx. Install the six .otf files in the Fonts folder first, then restart PowerPoint. Windows: select the font files, right-click and choose Install. macOS: open the font files in Font Book and install.

The editable deck uses TeX Gyre Schola and TeX Gyre Adventor to follow the supplied reference. The original handcrafted illustrations remain images. The submission PPTX stores each complete slide as an image to preserve its appearance; edit the separate native deck instead.

The PDF and submission PPTX have eight slides/pages. Do not upload both PPTX versions unless requested. Prefer the fixed submission copy when the form requires PowerPoint, or the matching PDF when allowed.

Font sources: TeX Gyre project via CTAN. Licence information is in the Fonts folder. No font is required to read the PDF or the fixed submission copy.
