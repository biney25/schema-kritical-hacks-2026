# Source provenance

Schema began before Kritical Hacks 2026. This repository preserves the earlier development history from https://github.com/biney25/schema-azinhack-2026, through commit `1be8ee5687d7b619cf0afd8cbd0fc84e9de71c57`.

The Kritical work adds bounded TinyFish event research, retrieval timestamps, per-field draft approval, date-range handling, provider and persistence checks, a reproducible command-line workflow, price economics and the eight-slide submission. The original AZINHACK repository is preserved separately.
